This project is a Lung Cancer Prediction System built using Machine Learning and Flask. It predicts the likelihood of lung cancer based on patient symptoms and health-related factors such as smoking, anxiety, wheezing, coughing, chest pain, fatigue, and other medical indicators. The system includes data preprocessing, model training, prediction, and a simple user interface for entering patient details and viewing prediction results.

Features:
1.Lung cancer prediction using Machine Learning
2.Data preprocessing and feature encoding
3.Model training and evaluation
4.User-friendly interface for input and prediction
5.Real-time prediction results
6Model saving using joblib (.pkl file)

Technologies Used:Python,Flask,Pandas,Scikit-learn,Joblib,HTML/CSS (for user interface)
